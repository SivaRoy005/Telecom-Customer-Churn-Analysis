# 📊 Telecom Customer Churn Analysis

## 📌 Project Overview
This project identifies the key factors causing customers to leave a telecom service. By using **SQL** for data extraction and **Python** for visualization, I discovered high-risk segments and provided recommendations to improve customer retention.

---

## 📂 Project Structure
* **`churn_analysis_queries.sql`**: SQL scripts for data setup and business metrics.
* **`Customer_Churn_Analysis_EDA.ipynb`**: Python notebook for data cleaning and visual analysis.
* **`graphs/`**: Exported visualizations showing key churn trends.
* **`Customer Churn dataset.csv`**: The raw data used for the project.

---

## 💡 Key Business Insights
* **Contract Risk:** Customers on **Month-to-month contracts** are the most likely to leave.
* **Payment Friction:** High churn rate observed among users paying via **Electronic Check**.
* **Financial Impact:** Customers with monthly charges above $70 show a sharp increase in churn.

---

## 🚀 Recommendations
1. **Contract Migration:** Offer discounts to move month-to-month users to 1-year or 2-year plans.
2. **Payment Incentive:** Encourage Bank Transfers or Credit Card payments to reduce payment-related churn.
